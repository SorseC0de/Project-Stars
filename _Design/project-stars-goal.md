# Project Stars Goal

> Project Stars is a survival game — damaging tiles is the cost, never the reward.


The goal of a Project Stars run is to **survive as many turns as possible**. The
board only ever degrades, so **damaging tiles is bad** — it is the price of
moving, not an achievement.

**Why:** this inverts how several abilities should be read. Doubling a sign's
tile damage is a *drawback* and belongs on that sign's weak plane; an ability
that defers or halves damage is a reward; and an effect that wrecks a lot of
board is a cost being paid for something else, not a payoff.

**How to apply:** when balancing, ask what an ability costs the board before
asking what it gives. Aries' Brazen Blaze is the worked example — it moves
damage behind the piece so fresh ground can be crossed, and charges for that by
doubling the damage, which is why the doubling sits on Astra where Aries is
weak. See [[zodiaction-charge-balance]].
